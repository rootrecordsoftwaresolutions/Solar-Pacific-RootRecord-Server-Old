# disk-session

See if a USB/SATA disk is present. River 2 Pro **car 12V** for drive power.

Dry-run default. Never AC. Starlink stays on Delta AC.

Owner natural language (“turn on the drives”) or `/skillrun disk-session --prepare --execute` PUTs car on. `--off --execute` after disk work. `--session --execute` runs the drive automation cycle (copy still stub). Anyone else gets status / dry-run only.
