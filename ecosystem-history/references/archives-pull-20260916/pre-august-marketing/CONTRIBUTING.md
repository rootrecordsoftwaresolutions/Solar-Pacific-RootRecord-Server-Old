# Contributing

Thanks for helping server owners discover and grow their communities.

## What to contribute

- New or corrected **listing site URLs** (add/update in `MARKETING-DEPLOYMENT.md` and `copy/server-listings.md`)
- Clearer **templates** in `copy/` — keep placeholders generic
- **Dead link** fixes — listing sites merge or shut down often
- Translations (optional) — consider a `locales/` folder if demand exists

## Style

- Use `{{PLACEHOLDER}}` for anything server-specific
- Player-facing economy: describe in-game currency generically unless documenting a real-money policy
- No pay-to-win assumptions — let owners fill features honestly
- Minimal diffs; one site or one doc per PR when possible

## Do not commit

- Filled-in `my-server-profile.md` with live IPs or tokens
- Votifier secrets, RCON passwords, or Discord bot tokens
