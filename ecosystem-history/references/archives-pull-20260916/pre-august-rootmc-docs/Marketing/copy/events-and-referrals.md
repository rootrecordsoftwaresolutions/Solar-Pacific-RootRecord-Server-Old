# Events & referrals — RootMC

Announcement copy for events, giveaways, and invite-a-friend campaigns.

**Economy note:** Automated payouts and grant-type rewards come from the **Server Reserve treasury** — not direct wallet mint. Player-facing copy uses **Gold (G)**.

---

## Generic event announcement (Discord + social)

```
📅 **Event: [Event Name]**

**When:** [Date/time + timezone, e.g. Sunday 18:00 HST]
**Where:** RootMC — play.rootmc.net · meet at [location/coords]
**What:** [Build contest / PvP tourney / treasure hunt / etc.]

**Rewards:** Treasury-funded Gold + [cosmetics/titles if applicable]
**Rules:** rootmc.net/wiki/constitution/ · fair play only

RSVP in thread 👇 · Questions in #general-chat
```
