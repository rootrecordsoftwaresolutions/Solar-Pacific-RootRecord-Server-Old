# FAQ & rules snippet — RootMC

Short blurbs for listing “FAQ” fields, Discord pins, and support replies.

Full rules: https://rootmc.net/wiki/constitution/

---

## One-paragraph rules summary (listings)

```
RootMC expects fair play: no x-ray, dupes, harassment, or unfair clients. Gold (G) is the only currency — economy rules are in our public Constitution. Automated rewards (votes, events, milestones) are paid from the Server Reserve treasury. Respect towns and Claims. Staff decisions follow the Constitution and player wiki. Full policy: rootmc.net/wiki/constitution/
```

---

## FAQ — How do I join?

```
Java Edition only. Multiplayer → Add Server → play.rootmc.net → Join. New player guide: rootmc.net/wiki/player/
```

---

## FAQ — Bedrock?

```
RootMC official servers are Java Edition. Bedrock is not supported unless announced on rootmc.net.
```

---

## FAQ — What is Gold (G)?

```
Gold is the in-game currency. Earn it by minting ore, trading, running shops, and receiving approved treasury grants (votes, playtime, events). All Gold is redeemable at the mint peg. Details: rootmc.net/wiki/economy/
```

---

## FAQ — Pay to win?

```
No. RootMC is built for long-term survival and trade — not paid ranks that buy power. Memberships or cosmetics (if offered) do not bypass Constitution economy rules.
```

---

## FAQ — Towny vs Claims?

```
Towny world: towns and nations. Claims world: personal claim plots. Progression (ranks, McMMO, votes) links between official worlds. Same join IP: play.rootmc.net.
```

---

## FAQ — How do votes work?

```
Vote once per 24 hours on each listing site for 1–20 G. Use /vote in-game or links on rootmc.net. Rewards are paid from the Server Reserve when the listing confirms your vote via Votifier.
```

---

## FAQ — Link Discord / stats?

```
Run /link in-game or visit rootmc.net/verify. Unlocks Discord role, public stats, and app features.
```

---

## FAQ — Where is the map?

```
https://map.rootmc.net — live BlueMap of the official worlds.
```

---

## FAQ — Cheating / reporting?

```
Report in Discord #ingame-feedback or to staff in-game. X-ray, dupes, and harassment are enforced. Evidence helps (screenshots, coords).
```

---

## FAQ — Governance / voting power?

```
Linked players can participate in Discord governance polls. Voting power uses playtime and listing vote history — see rootmc.net/wiki/constitution/#governance-voting
```

---

## FAQ — Starter items?

```
New players start at 0 G per Constitution. Essentials starter kit may include basic tools — check live config. No pay-to-skip progression.
```
