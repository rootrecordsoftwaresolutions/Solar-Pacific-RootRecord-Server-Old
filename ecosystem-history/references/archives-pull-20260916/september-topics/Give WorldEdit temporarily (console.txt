Give WorldEdit temporarily (console)
Full WorldEdit (typical staff temp grant):

lp user <username> permission set worldedit.* true 1h
Examples:

30m — 30 minutes
2h — 2 hours
1d — 1 day
From in-game (if you have LP access): /lp user <username> permission set worldedit.* true 1h

Remove it early (before expiry)
lp user <username> permission unset worldedit.*
Verify
lp user <username> permission info
Optional: smaller grant (not full WE)
If you only want selection + wand, not full admin WE:

lp user <username> permission set worldedit.wand true 1h
lp user <username> permission set worldedit.selection.* true 1h
Remove with permission unset on each node, or unset worldedit.* if you used the wildcard.

Note: LuckPerms temp perms expire on their own — you only need unset if you want to revoke early.
