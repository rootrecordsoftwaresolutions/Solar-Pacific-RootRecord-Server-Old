# Web Files

Active web applications live in the current project trees under this repository
and in the dedicated RootRecord repositories. Historical web snapshots are not
kept in the working tree.

The removed snapshots are retained on the external checkpoint drive at:

`CHECKPOINTS/09152026 prelinux/RootRecord Core/Web-Files/`

Use that checkpoint for historical comparison or recovery. Do not deploy from a
checkpoint copy without first promoting the required files into an active
project tree and validating its build.
