# Weather GIF collector (Windows AVA-CORE)

Live home on this PC. Desk **Weather GIFs → Open collector** opens this folder.

## Media

Collected / leftover GOES and Hawaiʻi-Pacific GIFs live under the Media public layout:

`C:\Users\rootr\ava\Media\public\images\weather\gifs`

(`current/` and `archive/` by region). That tree is on C: so Ava keeps working if D: or E: is unplugged.

## What is here

- `weatherGifLoop.py` — builds a looping GIF from hourly snapshots (recovered from the Aug 2026 archive).
- `archive-reference/` — old Node leftover modules and `weather-gifs.json` from OptiPlex-era Ava-core. Not started by Desk.

## What is not here

The Desktop folder `ava-weather-gif-collector-hawaii-pacific-v7.` (trailing period) and its `weathergifs.py` were not found on D: or E: archives. Do not recreate that Linux Desktop layout. Put any new collector scripts in this workstation folder.

## Start

No always-on collector service is wired on Windows yet. Run scripts from this folder when you want a pull; Desk only opens paths and reports leftover counts.
