3. MOJANG RULES (HOW WE INTERPRET THEM)
--------------------------------------------------------------------------------

Microsoft / Mojang have stated (paraphrased — read live docs for exact text):

  - Blockchain is not permitted INSIDE Minecraft client and server applications.
  - Minecraft in-game content must not be used to create scarce NFT-style assets.
  - EULA: no scarcity of in-game content based on OUT-OF-GAME conditions (e.g.
    a mod that checks NFT/token ownership to unlock skins, commands, or areas).
  - No play-to-earn: paying crypto for in-game activity is not allowed.
  - Commercial usage: cosmetic ranks and server access OK; gameplay advantages
    for real money are not OK.

Official links:
  https://www.minecraft.net/en-us/article/minecraft-and-nfts
  https://www.minecraft.net/en-us/usage-guidelines
  https://www.minecraft.net/en-us/eula

Precedent useful to us: off-game identity verification (e.g. World ID) that does
NOT gate gameplay with token ownership checks is treated differently from wallet
mods inside the server jar. Our model: verify/pay on WEBSITE → API flag → perks.

4. THREE-RING INTEGRATION POLICY
--------------------------------------------------------------------------------

Ring 1 — GAME (play.rootmc.net, Paper plugins, MySQL)
  $ROOTMC: NEVER
  G:        ONLY currency

Ring 2 — COMMUNITY (rootmc.net, Discord, events)
  $ROOTMC: optional supporter subs, badges, transparency, non-gameplay polls
  G:        documented in economy wiki; unchanged

Ring 3 — ON-CHAIN (pump.fun, wallets, DEX)
  $ROOTMC: trading, memes, creator fees
  G:        NO LINK

RULE: Ring 1 and Ring 3 never connect directly. No Solana RPC in plugins.

  - Education: G ≠ $ROOTMC messaging everywhere

6. PROHIBITED (NEVER IMPLEMENT)
--------------------------------------------------------------------------------

  - $ROOTMC as in-game currency or "deposit balance" spent like G
  - Airdrop G or items based on token holdings
  - Hold/pay X → cheaper town, shop tax, loans, grants, dividend multiplier
  - Exclusive worlds, kits, fly, McMMO boosts, extra homes (gameplay) for holders
  - In-game prefix/tab/badge driven by on-chain wallet checks in plugins
  - Paper plugins calling Solana RPC or reading wallet balances
  - Pay crypto for playtime, votes, PvP, milestones (play-to-earn)
  - NFTs or scarce in-game items tied to $ROOTMC
  - Implying Mojang/Microsoft endorses $ROOTMC
  - Using official Minecraft logos/assets to market the token as licensed product

If someone offers "RootMC holder" perks violating this list, treat as UNOFFICIAL
unless this doc + wiki are updated first.

7. SUPPORTER PROGRAM (PLANNED — COMPLIANT COSMETIC DONOR TIERS)
--------------------------------------------------------------------------------

CONCEPT
  Monthly COSMETIC supporter subscription. Players pay $ROOTMC on rootmc.net
  (wallet transaction). Cloud records donor_tier + expires_at on their linked
  account. Perks are vanity only — NOT a second currency.

SAY THIS                          | NOT THIS
----------------------------------|----------------------------------
"Supporter subscription"          | "ROOTMC currency on the server"
"Pay $ROOTMC on the website"      | "Deposit to use as money in-game"
"Cosmetic donor perks"            | "Dual economy" / "premium currency"
"G is still the only game economy"| "Tokenomics in survival"

REQUIREMENTS
  - User must complete existing Minecraft link (/rootmc link + verify) before
    supporter perks apply (same account_id in D1).
  - Payment verification happens on API / web only — never in Paper.
  - Plugin sync applies LuckPerms group or equivalent from cloud flag only.

ALLOWED PERKS (examples — finalize before launch)
  In-game (cosmetic only):
    - Tab list prefix / suffix (e.g. [Supporter])
    - Join/quit message styling
    - Particle trail or vanity pet (NO combat stats, NO gathering bonus)
    - Chat color (if purely cosmetic — no hidden commands)
  Off-game:
    - Discord donor role + optional private lounge channel
    - Web profile badge on rootmc.net/player/
    - Name on optional "supporters" page (opt-in)

NOT ALLOWED AS DONOR PERKS
  - /fly, /god, kits with items, McMMO XP, shop discounts, extra claims,
    treasury/dividend boosts, G stipends, vault slots with gameplay value

SUGGESTED TIERS (DRAFT — set amounts in ROOTMC after market review)

  Tier       | Draft ROOTMC/mo | In-game (cosmetic)     | Discord / web
  -----------|-----------------|------------------------|------------------
  Supporter  | TBD             | Prefix + join message  | Role + badge
  Patron     | TBD             | + particle trail       | + lounge access
  Benefactor | TBD             | + vanity pet (cosmetic)| + highlighted badge

Renewal: monthly; lapse removes groups/roles automatically when expires_at
passed (cron or sync check).
