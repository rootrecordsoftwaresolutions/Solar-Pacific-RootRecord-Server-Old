Super easy Litecoin mining guide

You will mine with XMRig (CPU) on unMineable and get paid in LTC. The referral code is already included so you pay lower fees.

Important: Mining uses electricity and CPU. Earnings depend on your hardware and electricity cost. This is not financial advice. Antivirus may flag mining software — that is common and usually a false positive.
1

Get a Litecoin wallet address

You need an LTC address that you control. Popular options:

  • Electrum-LTC or official Litecoin Core (desktop)
  • Exodus, Trust Wallet, or any non-custodial wallet that supports Litecoin
  • Exchange deposit address (only if you accept the risk of using a custodial address)

Copy the address (starts with L, M, or ltc1).

2

Download & run the one-file installer

The installer downloads the latest official XMRig, creates a config with your LTC address + our referral code, and starts mining. You only enter your address once.

Linux is “screensaver style”: mining is paused while you use the PC (almost zero CPU) and automatically switches to full speed after ~60 seconds of idle time.

Windows installer (.ps1) Linux installer (.sh)

Windows: Right-click the file → “Run with PowerShell” (or open PowerShell and run .\install-windows.ps1).
Linux: chmod +x install-linux.sh && ./install-linux.sh
Recommended: sudo apt install xprintidle (accurate idle detection)

3

Manual method (if you prefer)

1. Download XMRig from the official releases:

github.com/xmrig/xmrig/releases

2. Create a start script (Windows start.bat or Linux start.sh):

xmrig -o rx.unmineable.com:3333 -a rx -k -u LTC:YOUR_LTC_ADDRESS.worker#U-80KT6Z -p x

Replace YOUR_LTC_ADDRESS with your real address. You can change worker to any name you like.

3. Run the script. You should see hashrate appear after a few seconds.

4

Check your balance

Go to unMineable, search for your LTC address, and you will see your balance and workers.

Open unMineable (with referral)

Minimum payout for LTC is currently very low (around 0.00075 LTC). Payments are automatic.

Referral already applied

Using the code U-80KT6Z reduces the pool fee from 1% to 0.75%. This is already baked into the installers and the manual command above.

5

Tips for better results

  • Leave the miner running as long as possible (more time = more LTC).
  • On Windows, add an exclusion for the XMRig folder in Windows Defender if it gets deleted.
  • On Linux, enabling huge pages can improve hashrate (the installer can help).
  • You can run multiple PCs — just use different worker names.
